# Chat-Bot

## Project Description

This project is a web-based chatbot application. The front end is built with HTML for the structure, CSS for styling, and JavaScript for dynamic functionality. When a user sends a message, the application processes it and provides a response. This project demonstrates basic chatbot capabilities and user interaction.

## How to Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/codeash007/Chat-Bot.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Chat-Bot
    ```
3.  **Open the `index.html` file:**
    Simply open the `index.html` file in your web browser. This project is likely a client-side application and does not require a server to run.

## Features

*   Interactive chat interface
*   User input processing
*   Dynamic responses

## Technologies Used

*   HTML
*   CSS
*   JavaScript
