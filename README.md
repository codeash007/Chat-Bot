This project is a web-based chatbot application. The front end is built with HTML for the structure, CSS for styling, and JavaScript for dynamic functionality. When a user sends a message, the application sends a request to the Google Generative AI API (Gemini 1.5 Flash model) to generate a response. The conversation is displayed in a chat interface with distinct styles for user and AI messages. The user can send messages by clicking a button or pressing the "Enter" key. The chat interface includes user and robot avatars and a loading animation while the AI is generating a response.
